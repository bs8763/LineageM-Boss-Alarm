# 디스코드 봇 상시 운영 및 명령어 안내

## 현재 구조의 제약
현재 `render.yaml`은 Render 무료 웹서비스(`plan: free`)에서 웹과 Discord Gateway 클라이언트를 함께 실행합니다. 웹서비스가 절전 상태가 되면 Discord 봇도 오프라인이 됩니다. 코드에 재연결을 추가하는 것만으로는 절전 중 24시간 온라인을 보장할 수 없습니다.

**24시간 운영을 위한 필수 배포 변경:** 절전되지 않는 상시 실행 환경(유료 웹/워커 또는 무료 상시 실행이 실제 보장되는 별도 호스팅)을 확보해야 합니다. 서버 이전 전 기존 PostgreSQL 백업을 확인하고, 기존 Discord 봇 토큰과 서버·채널 ID는 안전한 환경변수로 옮기세요. Discord 봇을 두 인스턴스에서 동시에 실행하지 마세요. `DATABASE_URL`을 변경하거나 데이터베이스를 새로 만들 필요는 없습니다.

## 슬래시 명령어
- `/보스목록`: 등록된 보스의 맵, 예정 시간, 멍 횟수 확인
- `/보스등록`: `이름`(보스목록에 표시된 정확한 이름), `시간`(한국시간 `YYYY-MM-DD HH:mm`) 지정
- `/보스`: `동작`에서 `컷` 또는 `멍` 선택 후 `이름` 지정
- `/보스초기화`: 관리자만 사용. `확인=true`로 모든 보스 예정 시간과 멍 초기화. 실행 전 백업 확인 권장

`DISCORD_TEST_MODE=true`이면 슬래시 명령 앞에 `검증`이 붙고 지정된 테스트 채널에서만 처리됩니다.

## 일반 채팅 명령어 (선택 기능)
`DISCORD_TEXT_COMMANDS=true`와 `DISCORD_GUILD_ID`, `DISCORD_TEXT_CHANNEL_ID`를 설정하고 Discord 개발자 포털에서 Message Content Intent를 허용한 경우, 지정된 채널에서만 다음 명령을 사용할 수 있습니다.
- `보스이름 컷` — 예: `카스트 컷`
- `보스이름 멍` — 예: `카스트 멍`

`DISCORD_COMMAND_ROLE_ID`가 설정된 경우 해당 역할 또는 관리자 권한이 필요합니다. 일반 채팅 명령으로 보스 목록이나 전체 초기화는 할 수 없습니다.

## 장애 확인 순서 (휴대폰만 사용 가능)
1. Render 모바일 웹에서 서비스 상태와 Logs 확인: `Discord ready`가 있는지, 재시작/종료 로그가 있는지 확인
2. Render 서비스가 `Suspended` 또는 절전 상태라면 호스팅 상시 실행 여부부터 해결
3. 서비스는 실행 중인데 봇만 오프라인이면 `Discord login failed`, `Startup failed`, DB 연결 오류 및 토큰 설정 확인
4. `/readyz`는 DB 준비 상태만 검사하므로, 성공해도 Discord 연결 상태를 보장하지 않음
5. 운영 변경 후 실제 Discord 온라인 상태와 명령 응답, 10분/5분/출현 예정 알림을 검증

**주의:** 무료 Render 웹서비스를 외부 핑으로 주기적으로 깨우는 방식은 24시간 봇 운영을 보장하지 않습니다.
