# 리니지M 보스탐 + 디스코드

Node.js 20 이상 필요. `npm install` 후 `npm start`.

환경변수: `DISCORD_BOT_TOKEN` (봇 토큰), `DISCORD_CHANNEL_ID` (알림을 보낼 채널 ID), `PORT` (선택).

웹 주소의 `/`에서 보스 등록·수정·삭제. 디스코드에서 `/보스등록`, `/보스목록` 명령어 사용.

주의: 시범용 MVP입니다. 현재 로그인/접근제어가 없어 공개 인터넷에 그대로 배포하면 누구나 수정할 수 있습니다. `bosses.json`은 로컬 파일이므로 재배포 시 유실될 수 있습니다. 실제 운영 전에 인증·영구 DB·호스팅 설정이 필요합니다. 5분/10분 알림, APK 빌드 기능은 아직 구현되지 않았습니다.
